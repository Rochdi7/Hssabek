# CONSULTATIVE SELLING FRAMEWORK — By Sector (Darija)

> Instead of pitching, **diagnose first**. Open with a sector question, then branch. For each sector: the next question, the next response (mirroring their pain), and the recommendation tied to a real feature in the product.

---

## The opening message (universal)

```
مرحبا بيك 👋
باش نقدر نوجّهو ليك الحل المناسب، ممكن تقولي ليا شنو هو القطاع اللي كتخدم فيه؟
(مدرسة، مركز تكوين، عقار، وكالة أسفار، عيادة، مكتب محاسبة, قاعة رياضية، مطعم، call center...؟)
```

Then branch on their answer 👇

---

## 🏫 School / مدرسة

**Next question:**
```
عندك كتيرة ديال l'inscriptions و الرسوم الشهرية ديال التلاميذ صعيب تتبّعها؟
```
**Next response (mirror):**
```
فهمت — المشكل ماشي factura وحدة، المشكل هو **كل شهر** نفس الـ frais ديال بزاف ديال التلاميذ، و تتبع شكون خلّص و شكون لا.
```
**Recommendation → Recurring Invoices + Reminders + Customers:**
```
هاد الشي محلول: كل تلميذ = client، و كتفعّل **facture متكررة (recurring)** كل شهر otomatik، و النظام كيصيفط **تذكير** للي ما خلّصش. تشوف ديمو ب أسماء قسم ديالك؟
```

---

## 🎓 Training Center / مركز تكوين

**Next question:** *كتخدمو ب devis قبل التسجيل، و من بعد facture؟ و واش كاين دفعات بالتقسيط؟*
**Mirror:** *يعني الدورة عندها ثمن، الطالب كيخلّص بالتقسيط، و خاصك تتبع الباقي.*
**Recommendation → Quotes → Invoice + Payment allocations:**
```
كتصاوب **devis** للدورة، كتحوّلو l'**facture** بنقرة، و كل دفعة كتسجّلها فالنظام كيحسب ليك **الباقي otomatik**. حتى التذكير كيمشي بوحدو.
```

---

## 🏢 Real Estate / عقار

**Next question:** *كتكري ولا كتبيع؟ و واش عندك عمولات و مصاريف بزاف خاصك تتبّعهم؟*
**Mirror:** *المشكل عندك ماشي غير l'facture، حتى **المصاريف و العمولات** و معرفة الربح الحقيقي.*
**Recommendation → Invoices + Finance (expenses/incomes) + Reports:**
```
كتصاوب factures للكراء/البيع، و فنفس الوقت كتسجّل **المصاريف و المداخيل** ف module ديال Finance، و كيخرج ليك **تقرير** بالربح الصافي. كلشي ف بلاصة وحدة.
```

---

## ✈️ Travel Agency / وكالة أسفار

**Next question:** *كتخدمو ب عملات مختلفة (درهم، أورو، دولار)؟ و عندكم موردين (compagnies, hôtels)؟*
**Mirror:** *يعني عندك بيع للزبون + شراء من المورّدين + عملات مختلفة. تعقيد.*
**Recommendation → Multi-currency + Sales + Purchases:**
```
النظام كيدعم **عملات متعددة** للزبون، و عندك **module ديال المشتريات** للموردين (bons de commande, factures fournisseurs)، و كلشي مربوط فبلاصة وحدة.
```

---

## 🏥 Medical Clinic / عيادة

**Next question:** *كل مريض عندو facture/reçu؟ و واش كاين مواد و مخزون (أدوية، مستلزمات)؟*
**Mirror:** *خاصك reçu نظيف للمريض + تتبّع المخزون ديال المستلزمات.*
**Recommendation → Invoices + Inventory:**
```
كل مريض = reçu professionnel ب logo العيادة، و **module ديال المخزون** كيتبّع المستلزمات و كينقّص otomatik ملي تستعملهم. ديمو؟
```

---

## 📊 Accounting Firm / مكتب محاسبة

**Next question:** *كم client كتسيّرو؟ و واش بغيتو حاجة كتصدّرو منها بسهولة (Excel/PDF) للتصاريح؟*
**Mirror:** *يعني خاصك تسيّر بزاف ديال l'clients و تصدّر المعطيات بسرعة.*
**Recommendation → Multi-user roles + Reports + Exports:**
```
كتقدر تزيد **مستخدمين ب أدوار** (محاسب، viewer...)، و كل التقارير كتصدّرها **Excel/PDF/Word** بنقرة. مناسب بزاف لمكتب محاسبة.
```

---

## 🏋️ Gym / قاعة رياضية

**Next question:** *عندك منخرطين شهريين؟ كيف كتتبّع شكون جدّد و شكون لا؟*
**Mirror:** *المشكل: الاشتراكات الشهرية و التذكير بالتجديد.*
**Recommendation → Recurring Invoices + Reminders:**
```
كل منخرط = **اشتراك شهري otomatik**، و النظام كيصيفط **تذكير** قبل التجديد. ما تبقاش تتبّع بيدك.
```

---

## 🍽️ Restaurant / مطعم

**Next question:** *بغيتي factures للزبناء (traiteur/شركات) ولا تتبّع المخزون و المشتريات ديال المواد؟*
**Mirror:** *غالباً المشكل هو المشتريات و المخزون أكثر من l'factures.*
**Recommendation → Purchases + Inventory + Suppliers:**
```
عندك **module ديال المشتريات** (الموردين، bons de commande) و **المخزون** للمواد، و للعملاء الكبار كتصاوب factures professionnelles. كلشي مدمج.
```

---

## ☎️ Call Center

**Next question:** *كتفوترو l'clients ديالكم ب الساعات/المشاريع؟ و عندكم team كبير؟*
**Mirror:** *يعني فوترة بالمشروع + team كبير خاصو أدوار و صلاحيات.*
**Recommendation → Invoices + Multi-user roles & permissions:**
```
كتصاوب factures بالمشروع/الساعات، و كتسيّر **team ب أدوار و صلاحيات** (شكون كيشوف، شكون كيصاوب). كلشي منظّم و آمن.
```

---

## Closing the consultative loop (any sector)

After the recommendation, always end with a **low-pressure demo offer**, not a hard close:
```
أحسن حاجة: نصاوب ليك مثال حقيقي ب smiyt [القطاع/الشركة ديالك] دابا، تشوف بعينيك كيفاش غادي يخدم معاك 🙏
نبداو؟
```
